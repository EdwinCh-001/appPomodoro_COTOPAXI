# Spec 005 — Ajustar los tiempos del pomodoro
Estado: borrador
HU de origen: docs/historias/HU-005.md
- RF-1: CUANDO el usuario modifique los tiempos en la pantalla de ajustes y guarde, EL SISTEMA persistirá los cambios y los aplicará desde la siguiente fase. (Origen: HU-005).
- RF-2: CUANDO el usuario ingrese un valor no válido o vacío, EL SISTEMA bloqueará el guardado y notificará el error. (Origen: HU-005).
- RF-3: CUANDO el usuario elija restablecer valores, EL SISTEMA regresará la configuración a los valores por defecto (25 min estudio, 5 min descanso corto, 15 min descanso largo, 4 pomodoros). (Origen: HU-005).
