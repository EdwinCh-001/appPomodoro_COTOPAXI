# Spec 004 — Recibir aviso al terminar el tiempo
Estado: borrador
HU de origen: docs/historias/HU-004.md
- RF-1: CUANDO el temporizador llegue a cero con el dispositivo en sonido, EL SISTEMA emitirá una notificación local con sonido y vibración indicando la fase finalizada. (Origen: HU-004).
- RF-2: CUANDO el temporizador llegue a cero con la app abierta, EL SISTEMA mostrará un aviso visual directo en la interfaz. (Origen: HU-004).
- RF-3: CUANDO el usuario inicie el temporizador por primera vez sin permisos concedidos, EL SISTEMA solicitará formalmente el permiso de notificaciones. (Origen: HU-004).
