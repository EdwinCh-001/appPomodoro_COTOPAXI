# Spec 006 — Usar la aplicación sin registro, sin internet y sin publicidad
Estado: borrador
HU de origen: docs/historias/HU-006.md
- RF-1: CUANDO el usuario abra la aplicación por primera vez, EL SISTEMA mostrará directamente la pantalla principal del temporizador sin requerir registro ni inicio de sesión. (Origen: HU-006).
- RF-2: MIENTRAS el dispositivo carezca de conexión a internet, EL SISTEMA mantendrá operativas todas las funciones de conteo, avisos locales y ajustes. (Origen: HU-006).
- RF-3: MIENTRAS el usuario navegue por la aplicación, EL SISTEMA no presentará ningún tipo de publicidad o anuncio comercial. (Origen: HU-006).
